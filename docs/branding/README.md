# Branding assets

Social-media and internal branding imagery for corvus. The SVGs are the
canonical sources; all text is outlined as paths, so they render
identically without any installed fonts. PNGs are exports of the SVGs.
Masters carry no version number — stamp one ad hoc for a release if
wanted.

| File | Size | Use |
|---|---|---|
| `corvus-github-social.{svg,png}` (+`@2x`) | 1280×640 (2:1) | GitHub repository social preview |
| `corvus-linkedin.{svg,png}` (+`@2x`) | 1200×627 | LinkedIn link/post card |
| `crow-mark.{svg,png}` | 800×400 | Standalone crow silhouette mark |

Design concept and rules (palette, composition, typography) are in
[philosophy-corvid-cartography.md](philosophy-corvid-cartography.md).

Palette: ink `#161b23`, bird `#06080b`, cream `#e7e0cf`, gold `#c8a24e`.
